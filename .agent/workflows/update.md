# SDLC Progress Update Workflow

Use this workflow to consistently update project documentation after finishing a task or reaching a milestone.

1. **Review Recent Memory**: Analyze the last few interactions and file changes to identify new lessons or progress.
2. **Update Lessons Learned**:
   - If a bug was fixed or a mistake corrected, add an entry to [lessons_learned.md](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/lessons_learned.md).
   - Focus on: What happened, Why it happened, and how to prevent it.
3. **Update Changelog**:
   - Add a new entry or update the current date in [changelog.md](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/changelog.md).
   - Use standard categories: `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`.
4. **Final Review**: Ensure the documentation accurately reflects the state of the workspace.
