## Incident 1 — Lint: Linebreak-Style Errors (LF vs CRLF)

**Severity:** Low (does not affect runtime)  
**Root Cause:** When Git committed `docs/CHANGELOG.md` on 2026-06-23, it converted line endings from CRLF to LF (warned during `git push`). ESLint is configured to enforce CRLF on Windows. The LF-format file now fails lint checks.  
**Impact:** CI build will fail the lint gate if enforced. No functional impact.  
**Proposed Fix:**  
1. Add `.gitattributes` rule: `docs/CHANGELOG.md text eol=crlf`  
2. Run `git add --renormalize .` to fix existing files.  
3. Or configure ESLint `linebreak-style` to `"unix"` globally to unify across OS.
