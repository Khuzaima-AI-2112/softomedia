## Root Cause
The secret audit detected a hardcoded Gemini API key (`'AIzaSyAYgmZKRaGIiLjtNWCNmA2sTR2gPIxMV5o'`) in two backend utility scripts:
1. [check-models.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/ad-server/check-models.js#L6)
2. [test-gemini-2.0.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/ad-server/test-gemini-2.0.js#L7)

Both files attempt to fallback to this hardcoded API key if the environment variable `GEMINI_API_KEY` is not set:
```javascript
const apiKey = process.env.GEMINI_API_KEY || 'AIzaSyAYgmZKRaGIiLjtNWCNmA2sTR2gPIxMV5o';
```

## Impact
Exposing an active Google Cloud API key in repository source files is a high-severity security risk. If public or shared, this key can be compromised and used to abuse the Gemini API, exceeding quotas or incurring unexpected billing costs on the project.

## Proposed Fix
1. Modify [check-models.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/ad-server/check-models.js) and [test-gemini-2.0.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/ad-server/test-gemini-2.0.js) to only use `process.env.GEMINI_API_KEY` without a hardcoded fallback string.
2. Throw an error if `process.env.GEMINI_API_KEY` is missing (as already done in [test-gemini.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/ad-server/test-gemini.js)).
3. Revoke/rotate the leaked key (`AIzaSyAYgmZKRaGIiLjtNWCNmA2sTR2gPIxMV5o`) in Google AI Studio / Google Cloud Console to prevent misuse.
