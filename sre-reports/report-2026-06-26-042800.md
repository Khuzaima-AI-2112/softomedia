# SRE Incident Report
**Date:** 2026-06-26T04:28:00Z
**Incident Phase:** 7. Automated Testing (Unit & E2E)
**Workflow:** `/bigtest`

## Description of Failure
The E2E test suite failed with 43 tests failing due to `TimeoutError: page.goto: Timeout 30000ms exceeded.`. The failures are entirely concentrated in the tests that were recently refactored to remove inline `JSON.stringify` inside Playwright mock routes (`tests/telemetry_global.spec.js`, `tests/retailer_validation.spec.js`, `tests/playlist_e2e.spec.js`, `tests/loop_playback.spec.js`, `tests/loop_persistence.spec.js`, `tests/loop_builder.spec.js`).

## Root Cause Analysis
During the operational hygiene refactoring, `route.fulfill({ body: JSON.stringify(data) })` was replaced with `route.fulfill({ contentType: 'application/json', json: data })`. 

When Playwright's `route.fulfill()` receives the `json` option, it automatically sets the `Content-Type` header to `application/json` and serializes the object. By providing both `contentType: 'application/json'` and `json: data` in the same object, it is highly likely that Playwright threw an internal exception within the `route` handler (e.g., conflicting properties or unrecognized argument signatures), causing the mock to fail to respond. Because the mock handler crashed without fulfilling the request or continuing it, the frontend's `await fetch(...)` never resolved, resulting in an infinite loading state that caused `page.goto()` and subsequent assertions to timeout after 30 seconds.

## Impact
The core E2E suite is currently failing for critical business workflows, including loop playback, loop builder, telemetry processing, retailer validation, and playlist orchestration. The deployment pipeline is blocked.

## Proposed Fix
**DO NOT IMPLEMENT AUTOMATICALLY.**

1.  **Refactor Route Fulfillment:** Go through the identified test files and remove the explicit `contentType: 'application/json'` option where `json:` is used. The correct Playwright syntax is simply:
    ```javascript
    route.fulfill({
        status: 200,
        json: data
    });
    ```
2.  Alternatively, if the older mock structure is preferred, revert to using `body: JSON.stringify(data)` and suppress the `eslint` rule inline if it cannot be satisfied by `route.fulfill({ json: data })`.
3.  Re-run `npm run test:e2e` to verify the tests no longer timeout.
