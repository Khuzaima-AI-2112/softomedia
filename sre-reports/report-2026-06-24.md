# SRE Incident Report: Master E2E Sweep Failure
**Date:** 2026-06-24
**Execution Mode:** Analytical (Read-Only)

## 1. Incident Summary
The `/bigtest` master Playwright E2E suite (`npm run test:e2e`) was executed to verify system-wide stability across 17 phases. While 73 tests passed, the suite suffered a massive failure cascade with **61 test failures** and 14 skipped tests.

## 2. Root Cause Analysis
Based on the execution logs, the vast majority of failures are `TimeoutError: page.waitForSelector` and `Error: expect(locator).toBeVisible() failed`.
Specifically, elements such as `getByText('>99%')`, `[data-testid="network-map"]`, `getByText('BonVie Summer Demo')`, and `[data-testid="schedule-history-row"]` are failing to render or become visible within the expected timeout.

This indicates a systemic failure rather than isolated bug logic. Potential root causes:
1. **Database Seeding/Fixtures:** The frontend may be loading empty states because the mocked demo data (e.g. "BonVie Summer Demo") is not properly populating via the `SeedService` before the E2E suites run. 
2. **Environment Variables:** `ALLOW_DEMO_MODE=true` or API base URLs might not be correctly propagated to the frontend bundle during the automated test execution, causing API fetches to fail or bypass the demo overrides.
3. **Wait/Navigation Logic:** Playwright might be navigating before React finishes mounting or hydrating the data states.

## 3. Impact
- **Severe:** The E2E continuous integration pipeline is broken.
- **Affected Areas:** Demo Wizard workflows, Analytics loops, Admin validations, Retailer scheduling, Advertiser dashboards, and Global telemetry.
- **Current State:** The system is passing all unit tests but fails heavily during browser integration testing.

## 4. Proposed Fix (DO NOT IMPLEMENT PER /bigtest RULES)
1. **Audit Test Setup:** Inspect the global Playwright setup (`playwright.config.js` and global teardown/setup scripts) to ensure `SeedService.js` correctly seeds the database before worker execution.
2. **Review Playwright Timeouts:** Verify that the frontend is not experiencing unhandled Promise rejections during E2E runs (check the browser console logs in the Playwright trace viewer).
3. **Analyze Traces:** Download and review one of the generated trace zips (e.g., `npx playwright show-trace test-results\analytics_loop-Loop-Analyt-4a7b1-5-Analytics-has-date-picker-chromium\trace.zip`) to see visually where the app is stuck (e.g. infinite loading spinner vs blank page).
4. **Fix Seed State:** Ensure that E2E tests are isolated and the `demo_wizard` seeded data is reliably deterministic for `expect(locator).toBeVisible()` assertions.
