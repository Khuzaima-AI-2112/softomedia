# SRE Incident Report - /bigtest Failure

**Timestamp:** 2026-06-25T17:33:00-04:00
**Failed Phase:** Phase 7: Automated Testing (Unit & E2E)
**Command:** `npm run test:e2e`

## Root Cause
The Playwright test runner aborted execution during compilation because it attempted to compile and parse unmaintained specs inside [tests/legacy/](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/tests/legacy/). These legacy specs reference deprecated fixtures (like `adminPage` in `media_cloud_verification.spec.js` and `personas_mvp.spec.js`) and missing modules (like `./fixtures/factories.js` in `campaign_wizard_happy_path.spec.js`).

Although the changelog indicated that legacy tests were ignored, the root [playwright.config.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/playwright.config.js) only includes:
```javascript
testIgnore: '**/firestore-rules/**',
```
It does not contain an exclusion for `**/legacy/**`.

## Impact
All E2E tests (including the main `demo-wizard` test suites) are blocked from running because Playwright fails to compile the test tree.

## Proposed Fix
1. Modify [playwright.config.js](file:///c:/Users/ChrisFro/Desktop/EmoGini/softomedia-live2026/playwright.config.js#L29) to ignore the `legacy/` directory:
   ```javascript
   testIgnore: ['**/firestore-rules/**', '**/legacy/**'],
   ```
