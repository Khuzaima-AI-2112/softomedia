Architectural Overview

SoftoMedia Digital Signage Platform MVP

Executive Summary

The SoftoMedia platform is a hybrid retail-media ecosystem designed to manage and monetize digital screens across retail locations. Built on a scalable, cloud-native architecture, the system orchestrates content delivery via an hourly loop scheduling logic, ensuring predictable ad rotation while maintaining retailer control through a mandatory validation workflow. The platform is co-owned by SoftoMedia (Platform Operator) and its retail partners (Real-estate Hosts).

Key technical goals include high availability for screen playback, automated quality gates for deployments, and granular telemetry for proof-of-play attribution.

User Personas & Governance

The platform supports five core roles, each with distinct access levels and responsibilities:

Role Responsibility Key Capabilities
Super Admin Platform Governance Account management, global config, prioritization rules.
Retailer Admin Host Management Content validation, store profiles, local campaign execution.
Campaign Manager Operations Playlist building, asset management, scheduling orchestration.
Advertiser Monetization Creative upload, targeting request, performance tracking.
Technical Operator SRE / Ops Device provisioning, health monitoring, remote diagnostics.
Role-Based Access Control (RBAC) is enforced at the API layer via JWT tokens and Firestore security rules.

Google Cloud Ecosystem

The infrastructure leverages Google Cloud Project softomedia-live-2026 for all managed services, minimizing operational overhead while maximizing scalability.

The Cloud Build pipeline enforces custom quality gates, including:

  • Linting and Unit Testing (Vitest/Jest)
  • Coverage Threshold Enforcement
  • Playwright E2E "Gold Path" Verification
All deployments are immutable container images hosted in Artifact Registry.

Component Deep Dive

Ad Server (Backend)

A Node.js/Express service responsible for business logic, security, and scheduling. It implements a Repository Pattern with a built-in Resilience Engine (Circuit Breakers) for data access. Scheduling is managed by the Loop Generation Service and centralized BusinessHoursService.

Key Dependencies: @google-cloud/firestore, jsonwebtoken, zod (Validation).

Client App (Frontend)

A Vite-powered React application with a dual-persona design:

  1. Dashboard: Admin/Retailer interface using Tailwind CSS and Lucide icons.
  2. Player: Lightweight, robust playback engine with offline fallback and real-time telemetry buffering.

The "Golden Circle" of Operations

Broadcast reliability is ensured through a three-step cycle:

  1. Generation: Loops are generated daily at 00:00 for the following day (D+1).
  2. Validation: Retailers preview and approve schedules via the dashboard.
  3. Orchestration: Screens poll the API, download assets to local storage, and execute the loop.
Playback telemetry is buffered in localStorage and uploaded in batches to prevent data loss during connectivity drops.
