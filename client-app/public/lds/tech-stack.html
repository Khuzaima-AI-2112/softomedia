Technology Stack

A comprehensive overview of the SoftoMedia Ad Network technical ecosystem.

Core Philosophy

Our stack is chosen for scalability, maintainability, and developer velocity. We leverage managed cloud services to minimize infrastructure overhead while maintaining a robust, containerized application layer. All core components are strictly versioned and subject to automated quality gates during the build process.

Frontend Architecture

React Ecosystem

  • Framework: React 18
  • Build Tool: Vite 5
  • Routing: React Router 6
  • Icons: Lucide React

Styling & Design

  • Engine: Tailwind CSS 4
  • Processing: PostCSS & Autoprefixer
  • Design System: Lifecycle Design System (LDS)

Backend Architecture

Runtime & API

  • Runtime: Node.js
  • Framework: Express
  • Language: Modern JavaScript (ESM)
  • Compression: Gzip (compression)

Security & Data

  • Auth: JWT & bcryptjs
  • Validation: Zod & Express Validator
  • Logging: Winston

Infrastructure & Cloud

Google Cloud (GCP)

  • Project: softomedia-live-2026
  • Database: Cloud Firestore
  • Storage: Cloud Storage (Media Assets)

Deployment

  • Containerization: Docker
  • CI/CD: Google Cloud Build
  • Hosting: Cloud Run (Serverless)

Verification & Quality

Testing Frameworks

  • E2E Testing: Playwright
  • Unit/Integration: Vitest (FE) / Jest (BE)
  • Maturity: Capability Maturity Model (CMM)

Governance

  • Linting: ESLint
  • Hardening: Phase 8 Auth Audit
  • Schema: Firestore Schema Enforcement
