SoftoMedia Ad Network - Technical Documentation

Last Updated: January 14, 2026

Overview

The system uses Firestore with a flat collection structure. Cross-references are maintained using document IDs string references.

Core Collections

retailers

FieldTypeDescription
idStringUnique retailer ID (e.g., ret_001)
nameStringFull name of the retailer
logoStringEmoji or URL to logo
contact_emailStringAdministrative contact
statusStringactive, inactive

locations

FieldTypeDescription
idStringRegion ID (e.g., loc_downtown)
nameStringDisplay name
typeStringregion, district, etc.

stores

FieldTypeDescription
idStringStore ID (e.g., str_001)
retailer_idStringReference to retailers
location_idStringReference to locations
nameStringStore display name
screen_countNumberNumber of active screens
traffic_levelStringhigh, medium, low

screens

FieldTypeDescription
idStringUnique ID (e.g., scr_001_01)
screen_idStringHardware serial or ID
statusStringonline, offline
store_idStringReference to stores
last_seenStringISO Timestamp of last heartbeat

Advertising & Content

campaigns

FieldTypeDescription
idStringCampaign ID (e.g., cmp_001)
advertiser_idStringReference to advertisers
nameStringCampaign name
statusStringlive, paused, completed
creative_urlStringPrimary asset URL
budgetNumberCampaign budget
spentNumberActual spend to date

media

FieldTypeDescription
idStringAsset ID (e.g., asset_001)
file_typeStringimage, video
durationNumberPlayback duration in seconds
urlStringStorage URL

Pricing & Operations

pricing_config

FieldTypeDescription
idStringAlways global
schemaVersionNumberSchema version (e.g., 1)
baseCPMNumberAnchor price per 1000 impressions
trafficTiersMap<String, Object>Keyed by tier name (e.g. 'high'). Contains multiplier, label, color, hours.
dateOverridesMap<String, Object>Keyed by YYYY-MM-DD. Contains multiplier, label, optional hourlyTiers.
retailerOverridesMap<String, Object>Retailer-specific adjustments

loops

FieldTypeDescription
idStringFormat: {screen_id}_{date}_{hour}
screen_idStringReference to screens
dateStringYYYY-MM-DD
hourNumber0-23
slotsArray12 slots with booking metadata
