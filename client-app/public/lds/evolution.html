Key Lessons Learned

50+ documented insights from the development journey

🔥 Critical

Never Use Default Secrets

Using fallback secrets (e.g., JWT_SECRET || 'default') creates critical security vulnerabilities.

Always fail fast with process.exit(1) if required secrets are missing. Forces proper configuration.

⚡ Performance

Firestore Count Optimization

count() implemented by fetching all documents in memory – O(n) operation.

Use Firestore's native .count() aggregation for O(1) performance and reduced network egress.

🧪 Testing

API Mocking in Playwright

Tests depended on backend endpoints that weren't fully implemented, causing flaky failures.

Use page.route() to mock API responses in beforeEach – isolates tests from backend state.

🏗️ Architecture

Service Layer Separation

Business logic mixed with data access made testing difficult and created tight coupling.

Routes → Services → Repositories. Services own business logic, repositories own I/O.

🔒 Security

Cloud Run Public Access

Deployment succeeded but app returned 403 Forbidden – IAM not configured properly.

Explicitly grant roles/run.invoker to allUsers for public-facing services.

🛡️ Resilience

Circuit Breaker Pattern

Transient Firestore timeouts blocked the entire event loop when many requests waited.

Implement Circuit Breakers for external resources – fail fast after threshold, recover in HALF_OPEN.

📦 CI/CD

SHA-Based Image Tagging

Overwriting :latest tag with failing builds made instant rollbacks impossible.

Implement unique $BUILD_ID or SHA-based tagging for every deployment. Never rely on :latest alone.

🧪 Testing

Material Icons Pollution

Icons like <span>add</span> polluted accessible names, breaking getByRole selectors.

Always use aria-hidden="true" on decorative icons inside interactive elements.
